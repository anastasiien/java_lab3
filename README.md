# Диспетчерская беспилотных такси

Многопоточная симуляция таксопарка на Java. Каждое такси работает в своем потоке, диспетчер распределяет заказы из общей очереди, пользователь отправляет команды из консоли, и все это происходит одновременно. Такси расходуют заряд, сами решают, когда пора заряжаться, а клиент может отменить заказ.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=openjdk&logoColor=white)

Учебный проект по многопоточному программированию.

## Как устроено

```
 Консоль (ввод команд) ──► BlockingQueue<Order> ──► Диспетчер ──► Taxi-0 / Taxi-1 / Taxi-2
                                                                  (каждое в своем потоке)
```

- **`ConsoleInput`** - поток, который читает команды пользователя и кладет заказы в очередь.
- **`Dispatcher`** - поток, который берет заказ из очереди и назначает его ближайшему свободному такси с достаточным зарядом (расстояние считается по манхэттенской метрике). Если подходящего такси нет 5 попыток подряд, заказ снимается как невыполнимый.
- **`Taxi`** - поток-такси, конечный автомат с состояниями `FREE → GOING_TO_CLIENT → DRIVING → FREE / CHARGING`. Поездка расходует 5% заряда на единицу расстояния. Свободное такси само уезжает на зарядку, если заряда не хватит на следующий заказ в очереди или если он ниже 50%.
- **`Order`** - заказ с координатами и флагом отмены.
- **`Logger`** - синхронизированный вывод с временем и именем потока, чтобы было видно, какой поток что делает.

## Синхронизация

| Механизм | Где и зачем |
|---|---|
| `BlockingQueue` | потокобезопасная очередь заказов между консолью и диспетчером |
| `ReentrantLock` + `Condition` | защита состояния такси; диспетчер будит поток такси сигналом при назначении заказа |
| `AtomicBoolean` | флаг отмены заказа, который меняется из одного потока и читается из другого |
| `volatile` | флаг запущенного стресс-теста |
| `synchronized` | логгер, чтобы строки от разных потоков не перемешивались |

## Команды

| Команда | Действие |
|---|---|
| `order x1 y1 x2 y2` | заказ из точки (x1, y1) в (x2, y2) |
| `cancel` | отменить последний заказ (нельзя, если клиент уже в машине) |
| `status` | состояние, заряд и позиция каждого такси |
| `history` | история поездок и зарядок |
| `test` | стресс-тест: средняя, высокая и малая нагрузка случайными заказами, включая отмены |
| `exit` | выход |

## Запуск

Нужна Java 17+.

```bash
javac -encoding UTF-8 *.java
java Main
```
